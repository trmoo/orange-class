# 🍊 오렌지 데이터 교실

고등학교 「데이터 과학」 워크북 **「오렌지로 데이터 분석 UP」** 을 따라가는 단원별 학습 앱입니다.
핵심 개념을 직접 조작하며 복습하고, 오렌지(Orange) **3.40** 의 위젯 흐름과 설정을 미리 연습한 뒤
실제 오렌지에서 프로젝트를 하도록 돕습니다.

## 단원 (7개, 단원마다 입장 코드)

| 단원 | 내용 | 교재 |
|---|---|---|
| 1 | 데이터 이해와 준비 — 형태·속성·통합·데이터베이스·수집·전처리·정규화·시각화·상관계수 | 2~8쪽 |
| 2 | 데이터 모델링과 평가 — 모델 4갈래·최소 제곱법·기계학습 회귀·오차·R²·k-평균·실루엣·지지도/신뢰도/향상도 | 9~13쪽 |
| 3 | 데이터 과학 프로젝트 시작하기 — 6단계·체크 사항·수집 체크리스트·주제와 분석 방법·오렌지 준비 | 14~17쪽 |
| 4 | 프로젝트 1-1 수면 시간과 비만율 (단순 선형 회귀) | 18~25쪽 |
| 5 | 프로젝트 1-2 식생활과 비만율 (다중 선형 회귀) + 내 프로젝트 | 26~35쪽 |
| 6 | 프로젝트 2 날씨와 옷차림 (k-평균 군집) + 내 프로젝트 | 36~47쪽 |
| 7 | 프로젝트 3 외국인 친구 여행지 추천 (연관 분석) + 내 프로젝트 | 48~59쪽 |

카드 한 장에 개념 하나나 활동 하나만 담아 교실 화면(1280×720)에서 스크롤 없이 보이게 했습니다.
← → 키로도 카드를 넘길 수 있습니다.

## 수업에서 쓰는 법

1. `dist/index.html` 을 학생에게 나눠 주거나 컴퓨터실에 복사합니다 (더블클릭으로 열림, 인터넷 불필요).
2. 그 단원을 시작할 때 **입장 코드**를 칠판에 적어 줍니다. 코드는 교사용 파일 `입장코드.md` 에 있습니다.
3. 교사는 **교사용 코드**를 넣으면 모든 단원이 한 번에 열립니다. 공용 PC 는 끝나고 [내 기록 지우기] 를 누릅니다.

- 입장 코드는 진도를 맞추는 **학습 장치**입니다. 개발자 도구를 아는 학생은 우회할 수 있습니다.
- 코드를 바꾸려면 `npm run codes` → `npm run build`. 코드를 만드는 낱말 목록은 로컬 전용 파일
  `tools/codewords.local.json` 에 있고 저장소에는 올리지 않습니다(목록이 공개되면 해시를 맞춰 보는 것만으로 코드가 드러나므로).
  **입장 코드 원문(`입장코드.md`)과 낱말 목록은 이 저장소에 없습니다.**

## 개발

```bash
npm install
npm start            # 개발 서버 (index.html)
npm test             # 계산·데이터·입장 코드 시험
npm run check:syntax # 소스 전수 문법·저작권 검사
npm run build        # dist/index.html 한 파일로 빌드 + 점검
npm run csv          # data/ 의 csv 두 개를 앱 안(src/data/csv.js)으로 옮겨 적기
```

앱 안에서 그래프·계산에 쓰는 데이터는 모두 **연습용으로 새로 만든 값**입니다(실제 통계 아님).
단, 4단원에서 내려받는 csv 두 개(`data/`)는 서울열린데이터광장의 **실제 통계**를 머리글만 한 줄로 정리한 것입니다.
